# Support Desk Hub

Build a "Support Tickets" page for a customer support app called SupportDesk AI.

Use this exact color palette:

- Background: #101820

- Card/panel background: #1B242C

- Raised surface: #242F39

- Primary/CTA red: #C63527

- Hover red: #7C2529

- Secondary/links blue: #171C8F

- Text: #FFFFFF (primary), #D0D3D4 (secondary), #78808A (low-emphasis)

- Success green: #31B456

- Warning yellow: #F8CE46

- Border: rgba(208,211,212,0.16)

The page should include:

- A header with "SupportDesk AI" title and a company logo area

- A row of stat cards: Total Tickets, Open, In Progress, Escalated, Closed

- A sidebar to filter tickets by Status and Priority

- A grid of ticket cards, each showing: ticket number, subject, customer name, priority badge, status badge, assigned agent

- Each ticket card has two buttons: "Assign" (opens a popup to pick an agent) and "Escalate" (opens a popup asking for a reason)

Dark theme throughout, modern and clean, matching a corporate support-desk product.
